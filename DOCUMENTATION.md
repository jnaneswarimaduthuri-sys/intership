# Project Documentation

## 1. Project Title

**Personal Portfolio Website**

## 2. Introduction

This project is a responsive personal portfolio website developed during my Codomax Web Development Internship.

The website is designed to present my educational background, technical skills, soft skills, projects, internship experience, certifications, resume, and contact information in a professional and user-friendly format.

## 3. Objective

The main objective of this project is to build a professional portfolio website using HTML, CSS, and JavaScript while gaining practical experience in frontend web development.

## 4. Technologies Used

* **HTML5** – Used to create the structure and content of the website.
* **CSS3** – Used for styling, layout, responsiveness, animations, hover effects, and visual design.
* **JavaScript** – Used to add interactivity and functionality.
* **Git** – Used for version control.
* **GitHub** – Used to store and manage the project source code.
* **GitHub Pages** – Used to deploy the website.

### File Description

Contains the main structure and content of the portfolio website.

**style.css**
Contains the styling, layout, responsive design, hover effects, transitions, and animations.

**script.js**
Contains JavaScript functionality such as button actions, form validation, resume download, and scroll-to-top functionality.

**README.md**
Provides a brief overview of the project.

**DOCUMENTATION.md**
Contains detailed information about the project.

**resume.pdf**
Contains my resume for download from the portfolio website.
